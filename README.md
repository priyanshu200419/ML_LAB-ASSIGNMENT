# 📘 Machine Learning Weekly Assignments

This repository contains weekly assignments completed as part of a Machine Learning course. Each assignment explores key ML concepts and implements algorithms using Python and essential ML libraries.

---

## 📅 Weekly Assignment Index

| Week | Topic Covered                           | File Name / Folder                       |
|------|-----------------------------------------|------------------------------------------|
| 1    | Introduction to Machine Learning        | `Week1_Intro.ipynb`                      |
| 2    | Linear Regression                       | `Week2_LinearRegression.ipynb`           |
| 3    | Logistic Regression                     | `Week3_LogisticRegression.ipynb`         |
| 4    | Decision Trees and Overfitting          | `Week4_DecisionTrees.ipynb`              |
| 5    | Support Vector Machines (SVM)           | `Week5_SVM.ipynb`                        |
| 6    | K-Nearest Neighbors (KNN)               | `Week6_KNN.ipynb`                        |
| 7    | Naive Bayes & Text Classification       | `Week7_NaiveBayes.ipynb`                 |
| 8    | Ensemble Methods (Random Forest, etc.)  | `Week8_EnsembleMethods.ipynb`            |
| 9    | Unsupervised Learning (K-Means, PCA)    | `Week9_UnsupervisedLearning.ipynb`       |
| 10   | Model Evaluation & Hyperparameter Tuning| `Week10_ModelEvaluation.ipynb`           |

> 📌 **Note:** Each week's folder or notebook includes detailed explanations, code, and visualizations.
